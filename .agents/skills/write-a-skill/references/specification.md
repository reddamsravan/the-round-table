1. Folder Structure:
- `SKILL.md`: Required main file for instructions.
- `scripts/`: Optional code and tools.
- `references/`: Optional guide files.
- `assets/`: Optional templates and data.
2. Frontmatter:
- `name`: 1-64 lowercase letters, numbers, and hyphens. Matches the folder.
- `description`: 1-1024 characters. States what it does and when to run.
- `disable-model-invocation`: Optional boolean to prevent automatic model run.
