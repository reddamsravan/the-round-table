# The Round Table

The Round Table provides skills for AI coding tools.

## Skills

- `/breakdown`: Splits plans into task trees.
- `/build`: Writes code and runs unit tests.
- `/commit`: Stages git changes and drafts commit notes.
- `/define`: Drafts specs and task rules.
- `/design`: Designs screen flows and interface rules.
- `/explain`: Explains code and ideas in plain English.
- `/interview`: Tests design choices with questions.
- `/learn`: Builds 30-day lesson plans.
- `/plot`: Plans system design and build tasks.
- `/prose`: Checks and writes clear text.
- `/review`: Reviews code diffs for quality.
- `/ship`: Makes git commits and writes retro notes.
- `/tdd`: Drives features and bug fixes through the red-green TDD loop.
- `/verify`: Checks task rules in the workspace.
- `/write-a-skill`: Create/Update skills.
